# Examples

Runnable Symo examples. Run one with:

```bash
pixi run ex examples/hello.mojo
```

Planned examples (added as features land):

- `hello.mojo` — toolchain smoke test (current)
- `build_expr.mojo` — build expressions with operators and the string DSL
- `differentiate.mojo` — symbolic differentiation
- `simplify.mojo` — simplification and canonicalization
- `evalf.mojo` — high-precision numeric evaluation via Decimo
